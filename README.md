# ⚾ 블러프볼 (BluffBall) 프로젝트 소개

블러프볼(BluffBall)은 투수와 타자 간의 정교한 심리전과 전략적 카드 배틀을 결합한 보드게임 기반의 웹/앱 야구 게임입니다. 단순한 피지컬 게임이 아닌, 상대의 수(숫자, 좌표, 타이밍)를 읽고 블러핑하는 두뇌 싸움의 재미를 극대화했습니다.

---

## 🎮 게임 모드 (Game Modes)

### 1. 싱글 모드 (1 vs 1 / 1이닝 승부)
* **특징:** 가장 기본이 되는 스피디한 핵심 모드(투수가 3장의 카드를 뽑음.)
* **매력 포인트:** 한 명의 플레이어가 투수와 타자를 모두 번갈아 가며 1이닝 동안 압축된 심리전을 펼치는 직관적인 모드

### 2. 클랜전 미니 모드 (4 vs 4 / 3이닝 승부)
* **팀 구성:** 클랜원 4명 [타자 3명 + 투수 1명] vs 상대 클랜 4명 [타자 3명 + 투수 1명]
* **매력 포인트:** 타자 3명이 각각 1~3번 타순을 맡아 3이닝 동안 공격을 진행하며, 팀원 간 음성 채팅이나 메신저를 통해 실시간으로 투수의 성향 및 카드를 분석하고 정보를 공유하는 전략적 팀플레이 모드 (플레이 타임 10~15분 내외)

### 3. 클랜전 정규 모드 (10 vs 10 / 9이닝 승부)
* **팀 구성:** 클랜원 10명 [타자 9명 + 투수 1명] vs 상대 클랜 10명 [타자 9명 + 투수 1명]
* **매력 포인트:** 본 게임의 **최종 엔드 콘텐츠**. 실제 야구처럼 1번부터 9번 타자까지 완벽하게 라인업을 짜서 펼치는 클랜의 명예가 걸린 9이닝 진검 승부

### 4. 커스텀 매치
* **특징:** 에너지 소모 없이 초대 코드를 통해 친선전을 즐기는 모드
* **방식:** 짝수 인원이 모여 매치 규칙을 자유롭게 선택하여 플레이 가능

> 💡 **교체 출전 룰 (클랜전/커스텀 공통):** > * 같은 팀 내의 타자와 투수는 교체 출전이 가능합니다.
> * 대판 투수로 등판하는 유저는 카드 4장을 선택하여 시작합니다.
> * 투수에서 물러나 타자로 교체된 플레이어는 해당 경기에서 다시 투수로 등판할 수 없습니다.

## 🛠️ 2. 배틀 단계 (매 투구 프로세스)

### 📌 핵심 진행 흐름
1. **투구 시작:** 투수는 원하는 [구종 카드]와 [시작 좌표]를 선택하여 투구를 시작합니다.
2. **타격 준비:** 타자는 투수가 선택한 [시작 좌표]를 확인한 뒤, 5초 이내에 투수의 [최종 좌표]와 [타이밍]을 예측하여 선택해야 합니다.
3. **스윙 판정:** * 타자가 선택한 좌표가 틀린 경우 ➡️ **[헛스윙]**으로 간주합니다.
    * 타자가 선택한 좌표가 맞은 경우 ➡️ 타이밍 일치 여부에 따라 **[타격 이벤트]**가 발생합니다.
4. **타격 이벤트 및 주사위 부여:** * **타이밍 완벽 일치:** 주사위 2개 부여
    * **타이밍 1칸 어긋남:** 주사위 1개 부여
    * **타이밍 2칸 이상 어긋남:** 타격 실패 ➡️ **[헛스윙]**으로 간주합니다.
5. **결과 정산:** 부여받은 주사위 눈금 결과에 따라 [아웃, 안타, 2루타, 3루타, 홈런, 병살타(주자 있을 시)]가 최종 결정됩니다. (볼 4개 누적 시 볼넷, 스트라이크 3개 누적 시 삼진)
6. **승리 조건:** 선택한 게임 모드별 이닝 동안 더 많은 점수를 낸 유저(또는 팀)가 최종 승리합니다.

---

### ⚾ 투수 세부 규칙 (Pitcher Rules)

* **구종 카드 관리:** 경기 시작 시 총 5장의 카드를 무작위로 뽑아 소지합니다. 카드에는 구종과 함께 **[구속 증가]** 또는 **[변화폭 증가]** 버프가 포함되어 있어 카드를 강화하여 사용할 수 있습니다.
* **구종 고유 속성:** 각 구종 카드에는 고유의 **[타이밍]**과 **[좌표 변화 값]**이 명시되어 있습니다.
    * *ex) 포심:* 좌표 변화 없음 / 빠른 타이밍
    * *ex) 슬라이더:* 좌표 변화 우로 2칸 이동 / 중간 타이밍
* **투구 메커니즘:** 투수가 던진 공의 [최종 궤적(좌표)]은 **'선택한 시작 좌표 + 구종 카드의 좌표 변화 값'**의 합산으로 결정됩니다.
* **⚠️ 좌표 '0' 예외 (폭투 규칙):** * 변화구의 최종 변화 값이 25개 격자 영역(스트라이크 9개, 볼 16개)을 벗어나는 경우 최종 좌표는 **'0'**으로 처리됩니다.
    * 만약 타자가 스윙을 하지 않고 좌표 **'0'**을 고른 상태에서 투수의 최종 결과도 **'0'**이 되면 **[폭투]**가 발생하여 루 상의 모든 주자가 한 베이스씩 자동 진루합니다.
    * 단, 삼진이나 볼넷 판정 상황에서 폭투가 터지면 타자 주자는 1루로 진루하며, 그 외 일반 상황은 '볼'로 판정합니다.

---

### ⏱️ 타자 세부 규칙 (Batter Rules)

* **스윙 미발동 시 카운트 처리:** 타자가 스윙을 하지 않은 경우(타임아웃 또는 좌표 0), 투수의 최종 구질이 스트라이크 존에 꽂히면 스트라이크, 볼 존에 꽂히면 볼 카운트가 올라갑니다.
* **⏳ 5초 타임아웃 :** 투수가 카드를 낸 후 5초 이내에 최종 좌표를 선택하지 못하면, 스윙 없이 투수의 투구 결과를 그대로 지켜봅니다.
* **💡 좌표 '0' 선택 :** 단순히 지켜보는 것을 넘어, 투수의 변화구가 영역을 벗어나 '0'이 되는 순간과 완벽히 맞물릴 경우 투수를 흔드는 **[폭투]** 조건을 발동시켜 공짜 진루를 짜릿하게 노릴 수 있는 고도의 전략적 선택지입니다.
